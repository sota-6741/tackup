# Design doc: 撤去タスク（ステップ7）

掲示終了を過ぎたのに、まだ撤去済みになっていない掲示物を、掲示板ごとの一覧（`/boards/{boardId}/removals`）に出す。
実際に掲示物をはがしたメンバーが「撤去済みにする」を押すと、掲示物の状態が撤去済みになり、一覧から消える。
PR は 2 つに分ける（一覧 → 撤去済みにする操作）。

根拠: [requirements.md](../requirements.md) の 15・32・34.3・34.5・34.7・37.7・38.5。画面は [screens.md](../screens.md) の S3。

## 構成

```text
/boards/{boardId}/removals
        │
 listRemovalTasks（所属を確認）
   1. PostRepository.findExpired（期限切れの条件・並び順・続きの取得）
   2. サムネイルの署名付き URL を並行に発行
        ▼
 RemovalTaskList ── 「撤去済みにする」 ──▶ removePostAction ──▶ removePost（所属を確認）
                                                              PostRepository.markRemoved
```

## 決めたこと

| 項目 | 決めたこと | 理由 |
| -- | -- | -- |
| 期限切れの条件 | SQL の条件を、公開中の条件と同じ Repository の中に置く。domain の `isExpired` と同じ決まりであることを、同じ例のテストで確かめる | 要件 32・37.5。無期限（`expiresAt` が `null`）は期限切れにならない |
| 並び順 | 掲示終了の古い順、同じ日時なら ID の小さい順 | 長く放置されているものから片づける |
| 続きの取得 | 並び順のキー（掲示終了と ID）を 1 つの文字列にして渡す。1 ページ 50 件 | 要件 34.5 |
| 索引 | `(board_id, expires_at, id)`、`status = 'published'` の行だけ | 一覧の絞り込みと並び順に合わせる |
| 見られる人 | その掲示板のメンバー（admin・poster） | 要件 2 の権限の表 |
| 表示する項目 | サムネイル・タイトル・掲示終了・期限超過時間。タイトルは掲示物詳細へのリンク | 要件 15。掲示板の名前は、掲示板ごとの画面なので見出しに出す |
| 期限超過時間 | 「3日超過」のように、いちばん大きい単位だけで出す（分・時間・日） | 細かい値は要らない。どれが古いかが分かればよい |
| 撤去済みにできる掲示物 | 状態が `published` の掲示物（期限切れかどうかは問わない） | 画面に出すのは期限切れだけだが、台帳（ステップ8）で無期限の掲示物を撤去済みにするときに同じ use case を使う |
| 撤去済みにする操作 | 押すと確認のダイアログを出す。確認したら `status = removed`・`removedAt`・`removedBy` を記録する | 撤去済みは元に戻せない。押し間違いを防ぐ |
| 同時の操作 | `status = 'published'` を条件にした 1 つの UPDATE で書き換える。すでに撤去済みなら、成功として扱う | 2 人が同時に押しても、記録（だれが・いつ）は先の 1 回だけ残る |
| ファイル | 撤去済みにしても消さない | 台帳で過去の掲示物を確かめられるようにする（要件 16） |
| 回数の制限 | 撤去済みにする操作を、ユーザーごとの書き込みの制限（`withRateLimit`）で包む | 要件 34.3 |
| 掲示板ボードからの導線 | ヘッダーに「撤去タスク」のリンクを足す | screens.md の「ヘッダーの導線」 |

## 検討した代替案

| 案 | 却下理由 |
| -- | -- |
| 所属するすべての掲示板の撤去タスクを 1 つの画面にまとめる | 要件の URL は掲示板ごと（`/boards/{boardId}/removals`）。まとめる画面は、必要になってから足す |
| 確認なしで撤去済みにし、「元に戻す」を出す | 元に戻す操作と、その間の状態を作る必要がある |
| 複数を選んでまとめて撤去済みにする | 1 件ずつで足りなくなってから足す |
| ヘッダーのリンクに、撤去待ちの件数を出す | 掲示板ボードを開くたびに数える問い合わせが増える。必要になってから足す |

## やらないこと

- 無期限の掲示物・期限前の掲示物を撤去済みにする画面（台帳。ステップ8）
- 撤去済みを元に戻す操作
- 期限切れの通知
