# コードの書き方

- `/** JSDoc */` は、名前と型から分からない振る舞い・理由・注意点があるときだけ書く。名前を言い換えない。`@param`・`@returns` に型を書かない。日本語で書く。interface の契約になる決まりは interface に書く。
- オブジェクトの引数は、シグネチャで分割代入して受け取る（1 段の省略記法のプロパティだけ）。
- 別の関数に値を渡すときは、スプレッドせずにプロパティを明示して並べる。スプレッドはオブジェクト全体を引き継ぐときだけ使う。
- 関数がその引数を 1 つのものとして扱うときは、引数に名前を付けたままにする（例: `hasRole(member, roles)`）。
