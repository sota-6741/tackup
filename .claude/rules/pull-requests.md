# プルリクエスト

- `main` はルールセットで保護されていて、直接 push できない。ブランチで作業して PR を作り、CI の `check` が通り、レビューの会話がすべて解決済みになったら、マージコミット（許可されている唯一の方法）でマージする。マージしたブランチは自動で消える。
- ブランチを push して PR を作る前に、`code-review` と `security-review` のスキルをブランチに対して実行し、見つかった問題に先に対応する（どちらも作業ツリーか `main` との差分を対象にできるので、コミット済みの変更もレビューできる）。
- CodeRabbit（`.coderabbit.yaml`）と GitHub Copilot（`.github/copilot-instructions.md`）が PR を自動でレビューする。ボットの指摘は、直すかどうかをそれぞれ判断し、ボットに返信せずに会話を解決済みにする。人のレビューの指摘は、直すか直さない理由を返信してから、会話を解決済みにする。
- PR のタイトルは `prefix: 日本語の説明` の形にする（prefix は `feat`・`fix`・`refactor`・`test`・`docs`・`chore`）。タイトルはマージコミットの件名になる。
